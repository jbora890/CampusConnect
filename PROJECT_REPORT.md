# CampusConnect – Final Project Report

## Project Title

**CampusConnect – Student Campus Event Management Website**

## Project Objective

The objective of this project is to develop a responsive and interactive website that helps students discover and participate in campus events. The project was created to apply the HTML, CSS and JavaScript concepts learned during the web development internship. It also demonstrates the use of Git and GitHub for version control and project deployment.

## Project Overview

CampusConnect is a student-focused campus event management platform. The website provides information about upcoming sports, cultural, technical and workshop events. Students can browse available events, search for specific activities and filter events according to their category.

The website contains four main pages: Home, Events, About and Registration. The Home page introduces the platform and highlights important events. The Events page dynamically displays available events and provides search, filtering, adding and deleting functionality. The Registration page allows students to register for an event using a validated form. Registration information is stored in the browser using LocalStorage.

## Technologies Used

The project was developed using HTML5, CSS3 and JavaScript. Semantic HTML elements were used to create a clear page structure. CSS Flexbox and Grid were used for layouts, while media queries were implemented to make the website responsive on desktop, tablet and mobile devices. JavaScript was used for dynamic content, DOM manipulation, event handling, search, filtering, form validation and LocalStorage.

## Main Features

The main features include responsive navigation, dynamic event cards, event search, category filtering, add and delete event functionality, registration form validation, automatic event selection through URL parameters and local storage of event and registration data.

## Challenges Faced

One challenge was designing a consistent responsive layout that worked across different screen sizes. Another challenge was implementing dynamic event management and form validation using JavaScript. Managing project files with Git and connecting the local repository to GitHub was also an important part of the project.

## Solutions Implemented

CSS Grid, Flexbox and media queries were used to solve responsive design requirements. JavaScript arrays and objects were used to store event information, while DOM manipulation was used to dynamically display and update event cards. LocalStorage was implemented to preserve events and registration information between browser sessions. Git was used to maintain project versions and GitHub was used for repository hosting and deployment.

## Key Learnings

This project improved my understanding of responsive web design, semantic HTML, CSS layouts and JavaScript programming. I gained practical experience with arrays, objects, functions, DOM manipulation, event listeners and form validation. I also learned how to initialize a Git repository, create meaningful commits, push a project to GitHub and deploy a website using GitHub Pages.

## Future Improvements

Future versions could include user authentication, an administrator dashboard, a backend database, email notifications, event reminders and online attendance management. These improvements would make CampusConnect more suitable for real-world campus use.

# CampusConnect – Student Campus Event Management Website

## 📌 Project Overview

CampusConnect is a responsive and interactive student campus event management website developed as a final web development project.

The website provides students with a simple platform to discover upcoming campus events, search and filter events, register for activities, and manage events.

The project demonstrates practical knowledge of HTML, CSS, JavaScript, Git, GitHub, and responsive web design.

---

## 🎯 Project Objective

The main objective of CampusConnect is to create a user-friendly platform that makes it easier for students to discover and participate in campus activities.

The project also demonstrates the web development concepts learned during the internship, including semantic HTML, CSS layouts, responsive design, JavaScript programming, DOM manipulation, events, arrays, objects, and form validation.

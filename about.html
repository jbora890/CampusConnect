ABOUT THE PROJECT

Built for a more connected campus.

A simple digital hub for discovering, managing and joining student activities.

OBJECTIVE

Make campus participation easier.

CampusConnect was developed as a final web development project to demonstrate practical HTML, CSS and JavaScript skills through a useful student-focused application.

The platform organizes campus activities into searchable categories and provides an easy registration workflow.

100%

Designed around student usability and responsive web principles.
